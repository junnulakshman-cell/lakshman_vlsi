# Runtime Polymorphism in SystemVerilog

This folder contains the runtime-polymorphism example for the `oops` topic set.

It demonstrates how a base-class handle can point to a derived object and call the correct overridden method at runtime.

## Included files

- `virtual_runtime_polymorphism.sv` — the SystemVerilog implementation

## Related concept

This folder is part of the broader OOP examples and complements the other topic folders under `oops/`.
